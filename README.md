
# 🚀 ResumeRx AI

ResumeRx AI is an AI-powered resume analysis platform that helps users analyze, evaluate, and improve their resumes. Users can upload PDF or DOCX resumes and receive detailed feedback, including ATS scores, strengths, weaknesses, missing skills, and improvement suggestions.

The application also allows users to maintain a history of previously analyzed resumes and revisit any report.

---

## ✨ Features

### 🔐 Authentication
- User Signup
- User Login
- JWT-based authentication
- Protected user data

### 📄 Resume Upload
- Upload resumes in:
  - PDF format
  - DOCX format
- File validation
- Drag and drop upload support

### 🤖 AI Resume Analysis
The application analyzes resumes and generates:

- ATS Score
- Resume Summary
- Strengths
- Weaknesses
- Missing Skills
- Improvement Suggestions
- AI Resume Roast
- Grammar Score
- Readability Score
- Overall Resume Rating

### 📊 Analytics Dashboard
Users can view detailed analysis results including:

- ATS Match Score
- Grammar Score
- Readability Score
- Overall Rating
- Missing Industry Skills
- Resume Strengths
- Action Checklist
- AI-Powered Resume Feedback

### 🕒 Resume History
Users can:

- View previously analyzed resumes
- Search resumes
- Filter resumes by score
- Sort by latest or oldest
- View individual reports
- Delete reports
